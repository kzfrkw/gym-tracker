# Scope（要件層） - Gym Tracker

## 機能一覧

### ✅ 実装済み

| # | 機能 | 概要 |
|---|------|------|
| 1 | 認証 | Google SSO / 匿名ログイン（デバッグ用） |
| 2 | パターン管理 | パターン（テンプレート）の作成・編集・削除 |
| 3 | 種目管理 | パターン内の種目・目標セット（回数範囲）の設定 |
| 4 | セッション実行 | ステップ形式でセット入力（重量・回数）、前回値プリフィル |
| 5 | セット完了チェック | タップで完了マーク → Firestore には完了分のみ保存 |
| 6 | ドラフト自動保存 | AppLifecycle（onInactive/onPause）で SharedPreferences に保存・復帰 |
| 7 | セッション完了画面 | 前回比・PR判定・全種目サマリー表示 |
| 8 | 履歴（カレンダー） | 月カレンダー + 日付タップでセッション一覧・詳細 |
| 9 | 進捗グラフ | 種目別・セッションごとの最大重量グラフ（fl_chart）|
| 10 | 1RM推定 | Epley 式による全期間ベスト1RM 表示 |
| 11 | ホーム画面 | 直近セッション一覧、ドラフト自動復帰ナビゲーション |

## ユーザーストーリー（主要フロー）

```
1. 今日トレーニングする
   → パターンを選ぶ → 種目ごとにセット入力 → 完了 → サマリー確認

2. 先週の記録を確認する
   → 履歴（カレンダー）→ 日付選択 → セッション詳細

3. ベンチプレスが伸びているか確認する
   → 進捗 → 種目選択 → グラフ確認・1RM確認

4. 途中でアプリを閉じてしまった
   → 再起動 → ホーム画面でドラフト検出 → セッション画面に自動遷移

5. メニューを見直したい
   → 設定 → 種目一覧 → 追加・編集・削除
   → パターン編集 → 種目を入れ替え
```

## スコープ外（明示）
