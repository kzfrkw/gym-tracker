# Skeleton（骨格層） - Gym Tracker

## ナビゲーション設計

- **BottomNavigationBar なし**：ホームを起点とするスタック型ナビゲーション
- **AppBar** に戻るボタン（標準）+ 右側アクションアイコン（画面ごと）
- セッション中はホーム画面への戻りを禁止（バックジェスチャー無効化）。意図しない離脱でドラフトに頼るのは不安全なため

### セッション実行画面

```
┌─────────────────────────────┐
│ トレーニング中        [中断] │
├─────────────────────────────┤
│ ベンチプレス        [⇄ 変更]│  ← 今日だけ別の種目に差し替え
│ 2 / 5種目                   │
├─────────────────────────────┤
│  ┌─────────────────────────┐ │
│  │ セット1   8〜12回       │ │
│  │ [80] kg   [-] 10 [+]    │ │  ← 前回値プリフィル
│  │ 前回: 10回 / 80kg       │ │  ← カードタップで完了（緑）
│  └─────────────────────────┘ │
│  ┌─────────────────────────┐ │
│  │ セット2   ...           │ │
│  └─────────────────────────┘ │
├─────────────────────────────┤
│ [       次の種目へ        ] │
│ [前の種目へ]   [スキップ]   │
└─────────────────────────────┘
```

**種目の差し替え：**
```
[⇄ 変更] タップ
  └─ 完了チェック済みのセットがある場合
       「入力中の記録は破棄されます」確認ダイアログ
  └─ 種目選択シート（パターン編集と共通部品）
       - セッション内の他の種目はグレーアウト
       - 「新規登録」も可能
  └─ 選択 → 種目名・前回記録・重量プリフィルが新しい種目に切り替わる
           目標セット（回数範囲・セット数）は元の枠のまま
```
