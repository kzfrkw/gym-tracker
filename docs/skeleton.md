# Skeleton（骨格層） - Gym Tracker

## ナビゲーション設計

- **BottomNavigationBar なし**：ホームを起点とするスタック型ナビゲーション
- **AppBar** に戻るボタン（標準）+ 右側アクションアイコン（画面ごと）
- セッション中はホーム画面への戻りを禁止（バックジェスチャー無効化）。意図しない離脱でドラフトに頼るのは不安全なため

---

```

```
