# Strategy（戦略層） - Gym Tracker

## プロダクトブリーフ

### 誰のために？
自分自身、および近しい人（広く配布する想定はしない）。
- 週に数回、複数のパターンを交互に実施するスタイル
- ジム or 自宅でのウェイトトレーニングが中心
- 記録はシンプルに・手早く済ませたい
- 定期的にメニューを見直し・再構成する習慣がある

### 何の課題を解く？
| 課題 | 現状のペイン |
|------|-------------|
| 前回の重量・回数を忘れる | メモ帳や記憶に頼っており、セット開始時に迷う |
| 進捗が見えにくい | 「前回より強くなったか」を直感的に確認できない |
| 記録が途中で消える | アプリを切り替えるとセッション中の入力が失われる |

### どう解く？
- パターン（テンプレート）ベースで種目・セット数を管理し、毎回ゼロから考えなくていい
- セッション開始時に前回値をプリフィル → ワンタップで上書き
- AppLifecycle イベントでドラフト自動保存 → 復帰時に続きから再開
- セッション完了後に前回比・PR判定を表示してモチベーション維持

## ユーザーゴール（優先順）

1. **記録する**：セッション中の重量・回数を素早く入力し、保存できる
2. **振り返る**：いつどんなトレーニングをしたか、過去の記録を確認できる
3. **成長を実感する**：特定種目の重量推移・1RM推定を確認できる

## プロダクトゴール

- 自分が実際に毎回使いたいと思えるシンプルさを維持する
- Firebase + Riverpod によるリアルタイム同期とオフライン復帰を安定させる
- 将来的な機能追加（複数ユーザー対応・デフォルト種目セット提供など）に備えた設計を保つ
